## NTPC Simhadri HRMS Portal

A modern Human Resource Management System (HRMS) developed for NTPC Simhadri to streamline employee attendance tracking, shift management, and workforce monitoring.

# Features
Secure Employee Login
Attendance Tracking & Monitoring
Shift Schedule Management
Role-Based Access Control
Employee Dashboard
Supervisor Dashboard
Attendance Reports & Analytics
Real-Time Workforce Visibility

# Tech Stack
React.js
Vite
Tailwind CSS
Node.js
MSSQL

# Purpose

The portal aims to digitize attendance and shift management processes, improve operational efficiency, reduce manual effort, and provide accurate workforce insights for NTPC employees and administrators.
